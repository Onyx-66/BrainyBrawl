# 19 --- Visual QA Checklist

For every affected major UI screen:

-   [ ] 1080 × 2340 / 20:9 portrait verified
-   [ ] safe areas/system insets handled
-   [ ] top resource/navigation pattern consistent
-   [ ] primary CTA placement matches reference grammar
-   [ ] green positive/ready/correct actions
-   [ ] red destructive/wrong/cancel actions
-   [ ] yellow/gold reward emphasis
-   [ ] purple/blue/cyan accents consistent
-   [ ] rounded cards/buttons
-   [ ] bold, readable hierarchy
-   [ ] player/team cards consistent
-   [ ] timers/progress placed consistently
-   [ ] loading/empty/error/reconnect states
-   [ ] pressed/disabled/selected states
-   [ ] English/French/Arabic tested
-   [ ] RTL tested
-   [ ] no hard-coded production content
-   [ ] no hard-coded user-facing strings

If a difference exists, determine whether it is required by the GDD,
accessibility, responsiveness, or an intentional documented decision.
Only accidental visual drift should be fixed automatically.
