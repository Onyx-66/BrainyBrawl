# 18 --- Mockups Reference

Canonical visual asset: `mockups/UI_MASTER_REFERENCE.png`

Target: Samsung Galaxy A56-style 1080 × 2340, 20:9 portrait.

Use the master board before every UI implementation. Match its
composition, button placement patterns, navigation, top resource area,
cards, spacing, typography, semantic colors, gameplay HUD, timers,
progress, player/team cards, result/reward states, and popup/reaction
treatment.

Visual target characteristics: - deep navy background; - dark blue
panels/cards; - saturated purple/blue/cyan accents; - green
positive/ready/correct actions; - red destructive/wrong/cancel
actions; - yellow/gold rewards/Flames; - rounded components; - bold
friendly typography; - high contrast; - compact mobile-game hierarchy.

The board contains illustrative example data. Do not copy its sample
player names, scores, prices, questions, or rewards into production.

Written GDD/gameplay requirements remain authoritative if the visual
reference conflicts with behavior.

For screens not pictured, infer only the established visual grammar. Do
not invent product behavior.
